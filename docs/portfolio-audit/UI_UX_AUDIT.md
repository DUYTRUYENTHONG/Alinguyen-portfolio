## Accessibility, content, and release limits

The sampled menu, filters, role radios, case tabs, links, skip link, and focus return are operable in browser tests; the case tabs also respond to arrow keys. The UI supplies alternative text for visible images and honors reduced-motion preferences. Lighthouse Accessibility and SEO scored 100 in the controlled runs, which does **not** certify WCAG 2.2 AA. A screen-reader pass, detailed contrast/touch-target inspection on physical devices, and real-user INP are still missing. No contact form is present; contact actions use `mailto:`.

STOS is represented as a live **public product website** with owner-supplied screenshots and founder/builder attribution. The portfolio does not prove authenticated Studio/Insights behavior or customer impact, and AI suggestions remain planned. There is no verified in-development feature inventory; adding status labels for unverified work would imply a maturity level that the evidence does not support. [Editorial TODO](RELEASE_VERDICT.md): obtain product architecture, test evidence, and implementation ownership before expanding the case. The separate STOS site was not opened in this audit, following the owner's earlier direction.
