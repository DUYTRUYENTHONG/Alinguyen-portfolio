# Initial portfolio audit — 15 October 2026

## Source and baseline

The public baseline was the deployed [GitHub Pages portfolio](https://duytruyenthong.github.io/Alinguyen-portfolio/) at commit `b90a1e01`. It was opened in Google Chrome through Playwright before edits. The local repository was clean. At this initial-audit stage, the candidate was local; its later release is recorded in [release verdict](RELEASE_VERDICT.md).

The repository uses Next.js 16.4 App Router, React 19.3, strict TypeScript, npm lockfile, global CSS, self-hosted Inter and Archivo variable fonts, and a static `output: "export"` build. `/work/` and five static case routes supplement Home, About, and Credits. The GitHub Actions workflow runs `npm ci`, typecheck, lint, and build, then uploads `out/` for Pages. `NEXT_PUBLIC_BASE_PATH=/Alinguyen-portfolio` and trailing slashes support the repository subpath. There is no repository test script. At baseline, `motion` was installed for the role picker. Homepage sections, tabs, filter controls, mobile menu, visitor role selection, guide, and funnel are interactive.

The main navigation links to Ali Nguyen/Home, Highlights, Work, About, CVs, and Contact; a mobile drawer exposes the same route. Home contains the hero, project/customer cues, visitor role picker, selected work, interactive funnel, feedback, About, CVs, and Contact. The only frontend service call is the public visitor-count endpoint; external links lead to repositories and related products. Fonts are bundled locally. The workflow's `needs: build` gate prevents a failed build from deploying; its upload path is `out/`. No credential value was found in the tracked frontend source reviewed here.

## Design and platform observations

The black/white surfaces, blue action color, rounded cards, and Inter/Archivo pairing are coherent. The candidate keeps that system. Native headings, links, radio selection, tab controls, skip link, focus styling, and reduced-motion rules were present. The guide and funnel add personality; this pass did not remove them. Lighthouse accessibility is an automated signal only, not a WCAG 2.2 AA certification.

The baseline source has canonical URLs, robots.txt, sitemap.xml, route-specific titles/descriptions, a generated Open Graph image, and a favicon. Static-export routing uses base-path-aware links. The [production asset check](production-asset-checks.json) covered nine routes and 59 same-origin assets; the [production link inventory](production-link-checks.json) covered 24 internal targets without errors and recorded 12 external destinations. The public visitor API and external product sites were outside this isolated browser test; no form submission or email was sent.
