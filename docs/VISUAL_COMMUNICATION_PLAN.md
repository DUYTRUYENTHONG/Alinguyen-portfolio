## Visual system and rights

- Original inline SVG/HTML/CSS only for new conceptual diagrams. No third-party artwork is downloaded or hotlinked, so no new asset license is needed.
- Use existing `--ink`, `--muted`, `--line`, `--canvas`, `--blue`, Archivo and Inter, with neutral surfaces. Blue identifies boundaries or relationships, never a success score.
- Diagram labels remain readable in HTML at narrow widths. Nearby prose conveys their meaning, and decorative paths are hidden from assistive technology.
- Existing project images and brand marks retain their provenance in [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md).
