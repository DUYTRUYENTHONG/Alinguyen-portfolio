# User journeys — local static export

The journeys were exercised in Google Chrome against `/Alinguyen-portfolio/` at desktop and 390 px mobile widths. The [check log](journey-checks.json) gives exact assertions and timestamps. Browser QA blocked the visitor API to avoid recording synthetic visits; no email was sent. The [internal-link inventory](candidate-link-checks.json) covers nine routes and records external destinations without visiting the separate STOS site.

| Visitor | Path and observed outcome | Remaining friction |
| --- | --- | --- |
| Technical recruiter | Home states Applied AI/product focus. The header leads to About/experience; the primary action jumps to Work. The AI CV PDF returned HTTP 200 and Contact exposes `mailto:`. | The homepage is long, but direct header/hero actions bypass the full scroll. The CV's printed name and details need owner review before a new public release. |
| Engineering manager | Work directory → AI & data filter → KKBox case → role, technologies, evidence, limitations → Deep dive → refresh → browser Back/Forward → return to Work. The default Read and Skim panels now expose the prototype's limitations, and arrow-key tab movement works. | KKBox remains a local prototype; real-data model scores and a public source link are pending. Private product architecture and implementation decisions should be added only with owner-backed evidence. |
| Business collaborator | Commerce filter shows Growth Commerce OS, STOS, and Chợ Kênh. STOS's portfolio case has owner-supplied previews, a full-resolution image path, product role, and a contact link in the footer. | The public product UI does not independently prove authenticated workflows or commercial impact. The portfolio does not claim those results. |
| Mobile visitor | At 390 px, menu opens and Escape returns focus; the primary CTA reaches Work, direct project and Contact hashes land near their targets, and the CV/contact links resolve. No horizontal overflow was measured at 360, 390, 768, 1024, 1440, or 1920 px. | A physical-device screen-reader/touch-target pass and field INP measurement remain outstanding. |

The final [Chrome log](journey-checks.json) passed 12/12 checks in two isolated runs. Firefox and WebKit [smoke results](nonchromium-checks.json) cover mobile menu, Escape, Work anchor, no page errors, and zero overflow. [Resilience checks](resilience-checks.json) cover failed portrait loading, delayed assets, and long scrolling. [Baseline](baseline-capture-manifest.json) and [candidate](candidate-capture-manifest.json) captures provide visual evidence at six widths and interactive states. These checks do not replace a full accessibility conformance review.
